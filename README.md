# Репликация статьи "The Impact of Oil Price Shocks on the U.S. Stock Market" Killian & Park 2009 + адаптация для российской экономики

### Это репозиторий с данными, кодом и графиками, а аналитическую записку можно получить по почте o-shvetsov@mail.ru


Репозиторий состоит из папок двух видов:

1) `russian_...` - это папки, относящиеся к репликации на российских данных и адаптации модели к российской экономике
2) `original_...` - это папки, связанные только с репликацией статьи на основе американских данных

Папки делятся на три вида:

1) `..._data` - папка с данными
2) `..._paper` - исполняемый код для нашей работы
3) `..._paper_results` - результаты выполнения кода из папок `..._paper` (графики, таблицы, файлы R моделей)

Очевидно, самая интересная пользователю этого репозитория часть это то, что лежит в `..._paper`
