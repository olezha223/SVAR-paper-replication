# Репликация статьи "The Impact of Oil Price Shocks on the U.S. Stock Market" Killian & Park 2009 + адаптация для российской экономики

### Это репозиторий с данными, кодом и графиками, а аналитическую записку можно получить по почте o-shvetsov@mail.ru


Репозиторий состоит из папок двух видов:

1) `russian_...` - это папки, относящиеся к репликации на российских данных и адаптации модели к российской экономике
2) `original_...` - это папки, связанные только с репликацией статьи на основе американских данных

Папки делятся на три вида:

1) `..._data` - папка с данными
2) `..._paper` - исполняемый код для нашей работы
3) `..._paper_results` - результаты выполнения кода из папок `..._paper` (графики, таблицы, файлы R моделей)

Очевидно, самая интересная пользователю этого репозитория часть это то, что лежит в `..._paper`

---

## Структура `original_paper`

- `data_processing.ipynb` - код для чтения и первичной обработки данных
- `preliminary_diagnosis.ipynb` - код для формирования признаков для модели
- `bivariate_var` - модель с двумя переменными из статьи, вспомогательная интерпретация
- `fevd_table-v1` - FEVD для самой первой модели из статьи
- `fig4_cumulative_irf_bivar` - кумулятивные импульсные отклики для модели с двумя переменными
- `fig5_conditional_covariance` - код для подсчета графика условной ковариации
- `historical_decomposition-v1` - код для построения исторической декомпозиции в самой первой модели
- `svar-2` - код для построения главной SVAR модели (не спрашивайте почему 2)
- `irf-2` - код для построения импульсных откликов в главной SVAR модели
- `industry_svar` - код для построения SVAR модели где последнюю переменную заменили на отраслевую доходность
- `svar_model_infl` - код для построения SVAR модели где заменили на инфляцию по ИПЦ последнюю переменную 

## Структура `russian_paper`

- `data_processing.ipynb` - код для чтения и первичной обработки данных
- `preliminary_diagnosis.ipynb` - код для формирования признаков для модели
- `ts_analysis.ipynb` - код для построения графиков временных рядов через библиотеку plotly и визуального выбора спецификации теста на стационарность
- `stationarity` - тесты на стационарность для всех рядов в российской части статьи
- `model_1,2,3` - код для моделей из разделов 3, 4.1.1, 4.1.2 из отчета, данные до 2015 года
- `model_rub` - модель с курсом рубля на данных после 2015 года
- `model_industries` - модель для последующего индустриальных импульсных откликов как в оригинальной статье

Код для построения графиков внутри папок по аналогии с `original_paper`

## Инструкция по запуску кода на python 

```python
pip install uv
uv sync
```

Дальше можно спокойно запускать код для обработки данных, но в целом можно создать и свое окружение, ничего не изменится, сложных зависимостей там нет.
